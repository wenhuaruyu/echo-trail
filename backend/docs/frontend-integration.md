# 前端接入说明

> 当前阶段不开发前端。本文供后续前端使用真实后端接口时参考。

## 1. 基础地址

本地开发：`http://127.0.0.1:8000/api/v1`

接口文档：`http://127.0.0.1:8000/docs`

## 2. 身份处理

首次进入时调用`POST /sessions/anonymous`，将返回的`access_token`保存在浏览器本地。除健康检查和创建会话外，请求头均需携带：

```text
Authorization: Bearer <access_token>
```

令牌无效时，清除本地令牌并重新创建匿名会话。

## 3. 核心调用顺序

1. 创建匿名会话。
2. 获取歌曲及歌词。
3. 用户点击播放时提交`POST /play-events`。
4. 制作烫银票时先上传图片，取得`photo_url`。
5. 创建票根时提交歌曲、播放记录、省份、票种、编辑内容及防重复编号。
6. 查询票根列表和省份地图。

## 4. 图片上传

接口：`POST /uploads/ticket-photo`

请求格式：`multipart/form-data`，文件字段必须命名为`file`。支持JPEG、PNG、WebP，原始文件最大5MB。

成功后保存`data.photo_url`，并将其原样放入烫银票创建请求。不要自行拼接图片地址，也不要提交外部图片网址。

## 5. 防止重复生成

每次进入“生成票根”动作时创建一个UUID作为`idempotency_key`。网络重试时继续使用同一个值；用户主动再次制作时创建新值。

## 6. 本地跨域地址

后端默认允许：

- `http://localhost:3000`
- `http://localhost:5173`

正式部署时通过`CORS_ORIGINS`替换为实际前端域名。

## 7. 前端需保存的数据

- 匿名访问令牌；
- 当前歌曲编号；
- 当前播放记录编号；
- 图片上传返回的`photo_url`；
- 当前生成操作的`idempotency_key`。

不要在前端自行保存或推导共鸣人数、地图点亮状态，均以后端返回为准。
